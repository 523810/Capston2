[교환독서(Exchange Reading) 캡스톤 프로젝트 컨텍스트 요약본]

이 문서는 포스터 제작 AI에게 프로젝트의 전반적인 기술 스택, 핵심 기능, 그리고 개발 맥락을 전달하기 위해 작성되었습니다. 이 내용을 바탕으로 A2 규격의 졸업작품발표회 포스터에 들어갈 '프로젝트 설명'과 '시스템 구성도'를 디자인하고 텍스트를 작성해 주세요.

---

1. 프로젝트 개요
- 프로젝트명: 교환독서 (Exchange Reading)
- 행사명: 2026학년도 춘계 졸업작품발표회
- 목표: 개인의 독서 취향(독서 MBTI)을 분석하여 맞춤형 도서를 추천하고, 같은 취향/책을 공유하는 사람들과 온·오프라인 모임을 가질 수 있는 소통의 장 제공. '필사 전시'와 '물려주기'를 통해 책의 수명을 연장하는 선순환 독서 생태계 구축.

2. 시스템 아키텍처 (시스템 구성도 작성용 데이터)
[Front-End (Mobile & Web)]
- 기술: React / Flutter 기반
- 역할: 사용자 UI/UX 제공. 백엔드와 REST API 및 WebSocket 통신. 베스트셀러 랭킹 정보는 알라딘 API와 직접 통신하여 렌더링 속도 최적화.

[Back-End (API & Real-time Server)]
- 기술: Node.js, Express 프레임워크
- 실시간 엔진: Socket.io
- 인증/보안: JWT (JSON Web Token), bcryptjs (비밀번호 암호화)
- 역할: 비즈니스 로직 처리, 유저/모임방/게시글 CRUD, Socket.io를 활용한 실시간 양방향 채팅 방송(Broadcast) 처리, 사용자 프로필 통계(독서 온도) 자동 연산.

[Database & Cloud 인프라]
- 데이터베이스: MongoDB (Atlas) / Mongoose ODM
- 서버 호스팅: AWS EC2, PM2 (무중단 운영)
- 파일 업로드: Multer (로컬 스토리지 업로드)

[External APIs (외부 연동 서비스)]
- 카카오 도서 검색 API (Kakao REST API): 사용자가 책을 검색할 때 도서 메타데이터(제목, 저자, 썸네일 등) 불러오기.
- 알라딘 Open API: 도서 랭킹 및 베스트셀러 정보 연동.
- SendGrid API: 회원가입 및 비밀번호 찾기 시 보안을 위한 이메일 OTP(6자리 일회성 인증번호) 발송 및 검증.

3. 주요 기능 및 개발 맥락 (프로젝트 설명 작성용 데이터)
- 독서 MBTI & 맞춤 추천: 유저의 테스트 답변을 분석하여 성향(예: '감성충만 새벽독서가')을 도출하고 알라딘/카카오 API를 통해 장르 맞춤 도서를 추천함.
- 온/오프라인 모임방 & 실시간 채팅: 6자리 랜덤 초대 코드를 통한 프라이빗 방 입장 가능. Socket.io를 통해 모임방 멤버들 간의 지연 없는 채팅 구현.
- 마이페이지 & 독서 온도 (Gamification): 유저가 읽은 페이지 수와 완독한 책 수를 바탕으로 기본 36.5도에서 시작하는 '독서 온도'를 실시간으로 계산하여 동기 부여.
- 텍스트힙(필사 전시회): 감명 깊은 문구를 사진과 함께 공유. 피드 형태로 제공되며 좋아요(스크랩) 기능 제공.
- 책 물려주기(HandMeDown): 다 읽은 책을 '나눔' 또는 '교환' 타입으로 게시하여 다른 유저와 거래할 수 있는 게시판 제공.
